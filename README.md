# Energy Projects holding page

This repository contains the static HTML and CSS for the Energy Projects holding page, `energyprojects.online`.

## Deployment

The currently published website is hosted on Netlify under the `dapper-stardust-12411c` project. To enable automatic deployments, link this **existing** Netlify project to this repository's `main` branch, leaving the build command blank and setting the publish directory to `.`.

## Images

The four screenshots currently displayed are referenced from an immutable Netlify deployment URL, rather than stored in this repository. This preserves the published visuals when the HTML is deployed. For a fully independent source repository, copy the screenshots from the original website deployment package into `assets/` and change the HTML image paths to local files before removing the old Netlify deployment. Additional screenshots are available in the original deployment package.

## Contact

The contact email is `enquiries@energyprojects.online`, with forwarding handled by Porkbun. DNS is managed at Porkbun; avoid changing the existing MX/SPF records when linking Netlify.
